# Welcome

Each note in this folder is a Markdown file on your computer. Open the folder in Finder or Explorer and you will see this one as `Welcome.md`.

- Choose **New Note** to create another file.
- Edit the title above to rename the file.
- Folders you add are real folders on disk.

Tags live in a small file beside the notes, `.laya-tags.json`. **AI Tag** asks Laya, a model that runs on this computer, which of your tags apply. The first time, Laya Notes downloads the model once.
